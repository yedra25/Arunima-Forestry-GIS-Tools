# Forestry-GIS-Tools
A collection of custom Python and ArcPy geoprocessing tools for forest inventory analysis, ecological classification, forest management planning, and GIS workflow automation in ArcGIS Pro.

The following tools are currently included in the ArcGIS Pro Forestry Geoprocessing Toolbox, with additional tools to be added as development progresses:

- Auto PolyID Tool

- LGFU Tool

- Basal Area Tool **(Note: BaTable.py is a supporting Python module containing reference dictionaries used by the Basal Area Tool, rather than a standalone geoprocessing tool.)**

- Deer Thermal Cover Tool

- EcoSite Tool

- FEC EcoSite Predictor Tool
