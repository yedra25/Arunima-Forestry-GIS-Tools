# ArcGIS Pro Forestry Geoprocessing Toolbox

## Overview

This repository contains an expandable collection of custom Python and ArcPy geoprocessing tools developed to support forestry-related GIS analysis, forest inventory processing, ecological classification, wildlife habitat assessment, and forest management planning.

The tools are designed to automate repetitive geoprocessing tasks, improve workflow efficiency, support consistent data processing, and simplify the analysis of forestry datasets.

The toolbox is maintained as an ArcGIS Pro `.atbx` file, with the associated Python scripts and supporting modules organized separately in the `tools/` directory.

Additional tools and improvements will be incorporated as development progresses.

## Requirements

- ArcGIS Pro with a compatible Python 3 and ArcPy environment
- Access to the required input GIS datasets
- The Python scripts and supporting modules associated with the tools
- Any additional dependencies specified in the individual tool documentation

## Installation and Setup

### Step 1: Download the Repository

1. Open the main GitHub repository.
2. Click **Code → Download ZIP**.
3. Extract the ZIP file to a folder on your computer.
4. Keep the extracted `toolbox/` and `tools/` directories together.

Alternatively, clone the repository using Git if you are familiar with version control.

### Step 2: Add the Toolbox to ArcGIS Pro

1. Open ArcGIS Pro and create or open an existing project.
2. Open the **Catalog** pane using **View → Catalog Pane**.
3. Expand the **Toolboxes** section.
4. Right-click **Toolboxes** and select **Add Toolbox**.
5. Navigate to the extracted repository folder.
6. Open the `toolbox/` directory.
7. Select the `.atbx` file and add it to the project.
8. Expand the toolbox in the Catalog pane to view the available geoprocessing tools.

### Step 3: Connect the Python Scripts

Some tools reference external Python scripts that must be accessible for successful execution.

1. In the Catalog pane, expand the toolbox.
2. Right-click the required script tool and select **Properties**.
3. Open the **Execution** section.
4. Check the script file path.
5. If the path references a location that does not exist on your computer, browse to the corresponding `.py` file in the repository's `tools/` directory.
6. Save the changes.
7. Repeat for any other tools that require their script paths to be updated.

**Important:** Supporting Python modules must also be available to the scripts that import them. For example, the Basal Area Tool uses `BaTable.py`, which contains reference dictionaries required for its calculations.

### Step 4: Run a Geoprocessing Tool

1. Open ArcGIS Pro and add the required input datasets to your project.
2. In the Catalog pane, expand the forestry toolbox.
3. Double-click the tool you want to run.
4. Review the tool's input parameters and required fields.
5. Select the appropriate input dataset and configure the available parameters.
6. Specify an output location if required.
7. Click **Run**.
8. Review the geoprocessing messages and resulting outputs.

Refer to the individual tool documentation for tool-specific requirements, dependencies, and execution instructions.

**Note:** Some tools require fields or outputs generated by other tools and must be executed in the appropriate order.

## Important Notes

- The toolbox is intended for use with ArcGIS Pro.
- Some tools require specific input fields, data structures, or supporting Python modules.
- Script file paths may need to be reconfigured after downloading the repository.
- Users should review individual tool documentation before execution.
- Toolbox updates should be tested before replacing previously working versions.
