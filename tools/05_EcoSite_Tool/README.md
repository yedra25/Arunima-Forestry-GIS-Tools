# Provincial EcoSite Parse Tool   [ELC_Tool]

Processes provincial ecological site code strings and separates their numerous components into individual attribute fields for easier interpretation and analysis.
**Requirements:** Select the input feature class and the field containing ecological site codes.  Usually PRI_ECO or SEC_ECO.
**Output:** Additional fields of the separate ELC string elements, such as vegetation, soil depth, moisture, chemistry, and ecological classification number.
