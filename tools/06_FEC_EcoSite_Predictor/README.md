# Central Ontario FEC Code Predictor Tool   [FEC_Tool]
   
Predicts an older ecosite classification system for Central Ontario forests based on species composition.
Provide a FEC (forest ecosite classification) code of 11 through 35.  Uses a similar query code as found in OWHAMTool and SFMMTool, but has been enhanced for wider range of T1 eFRI species codes.

**Requirements:** Ensure the species composition fields have been parsed out using the eFRI Tool.
**Output:** An ‘FEC_Code’ field containing the predicted ecosite classification code for each forest polygon.
